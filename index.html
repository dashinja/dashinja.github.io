About

I'm Byron Miller. I spent a decade as a theatrical master electrician and lighting designer before trading the light board for the terminal — and I still approach code the same way: understand the vision, translate it into the technical language of the trade, execute precisely.

These days I build full-stack web apps, GraphQL APIs, and command-line tools, all collected on this hub. Design and functionality should engage the user and simplify decision making — everything here aims at that.
